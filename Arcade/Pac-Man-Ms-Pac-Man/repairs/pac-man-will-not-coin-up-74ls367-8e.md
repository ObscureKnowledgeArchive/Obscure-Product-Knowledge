# Board Will Not Coin Up


## Repair Case Summary

This page documents a firsthand **Board Will Not Coin Up** repair case.
It is intended for technicians and collectors troubleshooting original Pac-Man or Ms. Pac-Man arcade PCB hardware.

- **Date:** 2017-06-17
- **Board:** Original Pac-Man PCB
- **Category:** Coin / credit input
- **Symptoms:**
  - Board would not coin up through the credit switch on the test rig.
  - The board had been functional after an earlier repair and a new ROM set had been installed.
- **Diagnostic observations / tests:**
  - Schematic review indicated 8H (74LS367) handled credit and coin 2.
  - Replacing 8H did not fix the problem.
  - Replacing the 367 at 8E restored coin-up operation.
- **Components / locations investigated:** 8H, 8E, 74LS367
- **Root cause:** Faulty 74LS367 at 8E.
- **Repair:** Replaced the 74LS367 at 8E.
- **Result:** The board coined up and worked properly.
- **Repair note:** Operational lesson recorded with this repair: allow freshly repaired PCBs to run for at least an hour or two so additional temperature-related or secondary faults can appear.
- **Search terms:** Pac-Man will not coin up; credit switch; coin input; 8E; 8H; 74LS367; coin 2
- **Evidence:** Physically verified repair / firsthand repair log

## How to Use This Repair Record

This is a firsthand physical repair case. The same symptom on another Pac-Man or Ms. Pac-Man PCB can have a different electrical cause. Use the documented diagnostic observations and tests to guide troubleshooting rather than replacing a component solely because it repaired this board.
