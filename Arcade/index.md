# Arcade Repair Knowledge Archive

This section of the **Obscure Product Knowledge Archive** contains firsthand repair records, diagnostic findings, troubleshooting information, and technical documentation for vintage arcade hardware.

The emphasis is on documenting actual problems encountered with original hardware, including symptoms, diagnostic observations, components investigated, repairs performed, and the resulting behavior.

## Pac-Man & Ms. Pac-Man

Repair documentation for original **Pac-Man and Ms. Pac-Man PCB hardware**, including logic faults, video and sprite problems, sound failures, memory faults, ROM and socket problems, synchronization faults, power-supply issues, and other board-level problems.

[Browse the Pac-Man & Ms. Pac-Man PCB Repair Archive](/arcade/pac-man-ms-pac-man/)

## About These Repair Records

Entries in this archive are based primarily on firsthand repair work and physical testing. A documented repair should not be interpreted to mean that every machine exhibiting the same symptom has the same electrical fault.

The records are intended to preserve difficult-to-find diagnostic information and provide additional evidence for technicians, collectors, restorers, and others troubleshooting original arcade hardware.
